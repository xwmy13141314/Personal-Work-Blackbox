> **产品定位：** 隐私优先的个人 AI 工作日志 · 本地存储 · 开源可审计

---

## 1. 产品概述

### 1.1 背景与痛点

- 知识工作者每天在多个应用间频繁切换，大量工作产出散落在不同工具中
- 事后回顾"今天做了什么"成本高，写日报/周报耗时
- 现有方案（录屏、截图）数据量大、隐私风险高
- 云端时间追踪工具存在数据泄露风险

### 1.2 产品定位

- 隐私优先的个人 AI 工作日志工具
- 纯本地运行，不联网上传，数据只存本机
- 通过输入活动 + 窗口上下文 + 剪贴板三层采集，AI 自动生成日报/周报/月报

### 1.3 核心价值主张

```
零干预采集 → 智能分类 → AI 摘要 → 可直接使用的工作日志
```

## 4. 功能规格

### 4.1 采集功能

- **输入活动采集（含 IME 中文捕获）**：通过 KeyboardHook 结合 Windows IMM API，捕获按键事件并识别输入法组合文本，准确记录中文输入活动。
- **窗口切换追踪**：WindowTracker 周期性轮询前台窗口，记录进程名与窗口标题切换轨迹。
- **剪贴板监控**：ClipboardMonitor 监听系统剪贴板变化，捕获复制内容（经隐私过滤后留存）。
- **空闲检测**：IdleDetector 基于输入活动间隔判断用户离开状态，自动暂停采集并标记空闲时段。

### 4.2 隐私保护

- **首次启动告知弹窗**：PrivacyConsent 组件 + 后端 consent API，首次启动向用户明确告知采集范围与数据处理方式，需用户知情同意后方可使用。
- **应用黑名单**：支持按进程名配置黑名单，黑名单应用的输入与窗口内容一律不采集。
- **内容脱敏**：PrivacyFilter 对采集内容执行正则脱敏，覆盖以下敏感信息：
  - 身份证号
  - 银行卡号
  - 手机号
  - JWT Token
  - API Key
  - IPv4 地址
  - PEM 证书/密钥
- **隐私模式开关**：一键开启隐私模式，临时暂停全部采集，适用于处理敏感工作场景。
- **数据库加密（SQLCipher 可选）**：数据库支持启用 SQLCipher 透明加密，提供迁移方法与无 SQLCipher 环境下的优雅降级。

### 4.3 AI 报告

- **日报 / 周报 / 月报**：ReportGenerator 基于采集的活动数据，调用 LLM 生成结构化工作日志，支持按日、周、月三种时间维度输出。
- **多模型支持（OpenAI 兼容）**：LLMClient 兼容 OpenAI API 协议，可对接 OpenAI、DeepSeek、通义千问等兼容模型。
- **环境变量 API Key**：API Key 通过环境变量加载，不写入配置文件与数据库，降低密钥泄露风险。

### 4.4 应用分类

- **10 类预设规则**：AppClassifier 内置 10 类应用分类规则（含图标与正则模式），按优先级匹配：

  | 分类 | 图标 |
  |------|------|
  | 开发工具 | 💻 |
  | 浏览器 | 🌐 |
  | 通讯社交 | 💬 |
  | 办公文档 | 📄 |
  | 设计创作 | 🎨 |
  | 娱乐休闲 | 🎮 |
  | 系统工具 | ⚙️ |
  | 数据库 | 🗄️ |
  | AI 工具 | 🤖 |
  | 其他 | 📦 |

- **自定义正则扩展**：支持注入自定义规则，自定义规则优先级高于预设规则。
- **分类统计**：按分类维度统计各应用活动时长与次数。
- **历史回填**：支持对已有历史数据执行回填分类，保证存量数据与新规则一致。

### 4.5 专注模式

- **娱乐应用检测**：FocusModeManager 识别用户当前是否处于娱乐休闲类应用。
- **专注会话**：支持设定专注时段，期间记录专注时长并统计中断次数。
- **效率目标**：可配置每日专注时长目标，实时对比完成进度。
- **提醒通知**：检测到娱乐应用或长时间偏离目标时，通过 Notification 发出桌面提醒。

### 4.6 数据导出与 API

- **CSV / JSON 导出**：DataExporter 支持将活动数据导出为 CSV 或 JSON 格式，便于二次分析与备份。
- **本地 REST API（6 端点）**：RestAPI 提供本地 HTTP 接口，供第三方工具集成，共 6 个端点，覆盖数据查询、统计、导出等能力。

### 4.7 报告导出与可视化

- **报告 HTML 导出**：`report_exporter` 将日报/周报/月报 Markdown 渲染为自包含单文件 HTML（内联 CSS/SVG，无外部依赖，可离线打开、微信/邮件直发）。
- **macOS 风格卡片化排版**：Hero 标题区（类型胶囊 + 日期 + 模型元信息）+ 章节正文（h2 自动注入 emoji 图标）+ 时间分布环形图 + 页脚。
- **PDF 导出**：内置 `@media print`，浏览器 Ctrl+P 直接打出排版干净的 PDF；环形图采用静态 SVG，打印必显示（不依赖 JS 渲染）。
- **时间分布环形图**：`timedist_extractor` 复用 todo_extractor 模式，LLM 从报告"时间分布"章节提取 `[{category,minutes,percent}]`（容错 JSON 解析 + 百分比归一化）；`render_donut_svg` 纯 SVG 渲染，导出 HTML 与 app 内共用一处生成。
- **待办 CSV 导出**：待办列表导出 CSV（UTF-8 BOM，Excel 兼容），状态/优先级中文映射。
- **优雅降级**：LLM 提取失败时，导出仍成功（无图版）、app 内图区静默隐藏，不报错。

## 5. 技术规格

### 5.1 技术栈

- **后端**：Python 3.11+，ctypes（WH_KEYBOARD_LL 键盘捕获引擎），pywebview，pywin32
- **前端**：React 18，TypeScript，Tailwind CSS，Vite
- **存储**：SQLite（可选 SQLCipher 加密）
- **AI**：OpenAI 兼容协议

### 5.2 性能指标

- CPU < 1%
- 内存 < 100MB
- 每日数据 < 1MB
- 291 个测试通过

### 5.3 安全规格

- 纯本地运行，不联网
- API Key 环境变量加载
- 数据库可选加密
- 三层隐私过滤（应用黑名单 + 内容脱敏 + 隐私模式）
