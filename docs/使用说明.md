# 职迹 WorkTrace 使用说明

## 快速启动

1. 双击 `启动.bat`（首次运行会自动安装依赖），或直接运行 `dist/WorkTrace.exe`
2. 应用启动后进入 Web GUI 主界面（macOS 风格三栏布局）
3. 在右栏「录制控制」点击「启动」开始采集
4. 正常使用电脑，工具在后台静默记录
5. 需要日报时，切换到「报告」视图点「生成报告」

## 界面（Web GUI 三栏）

主界面采用 pywebview + React 实现的三栏布局（Windows 原生标题栏）：

| 栏 | 内容 |
|----|------|
| 左栏 | 导航（报告 / 统计 / 活动 / 待办 / 设置 / 关于）+ 搜索框 + Logo + 采集状态 |
| 中栏 | 当前视图内容 |
| 右栏 | 录制控制（启动 / 暂停 / 停止 / 隐私）+ 状态 + 日历 |

### 录制控制（右栏）

| 控件 | 功能 |
|------|------|
| 启动 | 开始采集输入活动、窗口切换、剪贴板 |
| 暂停 / 恢复 | 临时暂停或恢复采集 |
| 停止 | 完全停止采集，自动导出今日日志 |
| 隐私模式 | 一键开关，开启期间全部停录（可随时关闭或 30 分钟自动恢复） |

## 视图导航

### 驾驶舱视图

- 个人工作台首页：今日活动概览 + 速记条数/置顶数 + 待办统计汇总
- 一键跳转到速记 / 报告 / 待办

### 速记视图

- 输入框快速记录（Enter 保存 · Shift+Enter 换行），支持**标签**（逗号分隔，自动去重）
- 四指标：今日 / 本周 / 累计 / 置顶
- **标签云**：按出现次数排列，点标签即筛选，再点取消；搜索同时匹配内容与标签
- 卡片可置顶 / 取消置顶、删除（软删除）
- **全局快捷键 Ctrl+Alt+I**：任意界面呼出主窗口并跳转速记页、自动聚焦输入框
- **洞察收件箱（v5.4）**：工具栏「洞察收件箱」可配置一个目录——速记保存时同步落盘为该目录下的 Markdown（frontmatter 含 `type/created/tags/source`），供「每日洞察」档案的 AI 蒸馏流程增量消费；面板显示连通性、可写性与待处理文件数；留空 = 仅入库不落盘

### 报告视图

- 日 / 周 / 月报切换，日期导航
- 点「生成报告」由 LLM 生成（Markdown 渲染），正文下方自动渲染「时间分布」环形图（LLM 从报告提取，失败则隐藏）
- 录制中生成日报会自动包含当前会话内容
- **导出**：报告可导出为 macOS 风格单文件 HTML（含时间分布环形图，可离线、可微信/邮件直发），浏览器打开后 Ctrl+P 直接转 PDF；待办列表可导出 CSV（Excel 兼容）

### 统计视图

- 应用使用时长排行（今日 / 本周 / 本月）
- 条形图 + 总活跃时长

### 活动明细视图

- 按日期浏览会话列表（各应用 + 时长）
- 点开查看输入文本片段
- 左栏搜索框输入关键词，跨日期全文检索历史输入
- **拼音智能识别（v5.2）**：展开会话 → 点「智能识别」，离线引擎把拼音记录转成汉字（DAG 词库 → HMM → 单字映射三层兜底，纯本地）；识别不了的部分（简拼、英文、数字）保留原文——能识别的转汉字，识别不了的不乱转
- **AI 增强（v5.2）**：已配置 API Key 时，「智能识别」后出现「AI 增强」按钮，一次批量调用 LLM 重识别，对**简拼/混拼**（如 `jint`→今天、`wanc`→完成）还原效果最准；结果带 ✨ 高亮标识，与普通转换区分
- **真实上屏文本采集（v5.3）**：默认开启——输入提交入库前，系统会尝试读取窗口的真实上屏文本（UIA 快照 + WPS/Office COM 单元格级读取），替换键盘逆推的拼音；隐私模式 / 黑名单应用自动跳过，`config/config.yaml` 里 `accurate_mode` 可一键关掉回退纯键盘链路

### 待办看板视图

- 三列拖拽看板（待办 / 进行中 / 已完成），卡片可拖拽改状态、点复选框三态切换、调进度（满 100% 自动完成）
- 视图切换：**按状态**（三列可拖）/ **按来源**（手动 / 日报 / 周报 / 月报 四列只读）/ **归档**
- 「从报告提取」把日报中的可执行项提取到草稿区，确认后入库；「AI 建议」结合当日活动给推进建议

**删除归档（v4.4）：**

- 应用内删除的待办**不会真丢**：改打 `deleted_at` 时间戳隐藏，记录保留在数据库
- 删除时同步追加文件归档：`data/exports/todo_archive_YYYY-MM.md`（按月表格，可直接查看）+ `todo_archive.jsonl`（全字段备份）；文件只增不改，随时可找回
- 「视图 → 归档」可搜索（标题/备注）、**恢复**（回看板原位置）、**彻底删除**（两步确认，归档文件中的历史记录仍保留）

### 设置视图

设置页提供 API 配置表单、界面设置与数据目录入口。

**API 配置流程：**

1. 选择提供商预设（智谱 GLM / 阿里通义 / DeepSeek / Kimi / OpenAI / 自定义）
2. 填写 API Key
3. 点击「测试连接」验证密钥与模型可用性
4. 点击「保存」写入 `config/config.yaml`（重启生效）

**界面设置：** 字体大小三档切换（小 / 中 / 大，默认中），选择后即时生效并自动记忆。

所有提供商均为 OpenAI 兼容协议，新增厂商只需在前端预设加一条 + config 加字段。

### 常驻日历（右栏）

- 圆角方格日历，撑满右栏
- 双标记：有采集的日期显示蓝点，有日报的日期显示底色
- 支持周 / 月切换跳转

## 报告类型说明

| 类型 | 数据来源 | 输出文件 |
|------|----------|----------|
| **日报** | 单日活动数据（输入+窗口+剪贴板） | `2026-05-22_091156_report.md` |
| **周报** | 该自然周（周一~周日）内已有的日报汇总 | `2026-05-19_weekly.md` |
| **月报** | 该自然月内已有的日报汇总 | `2026-05_monthly.md` |

> **注意**: 周报和月报基于已有的**日报**汇总生成。如果某天缺日报，该天会被标注为缺失，不影响整体生成。请确保先为需要的日期生成过日报。

## API Key 配置（环境变量）

为避免密钥明文落盘，推荐通过**环境变量**提供 AI 提供商的 API Key。环境变量优先级高于 `config.yaml`，加载时自动覆盖文件中的 `api_key` 字段。

命名规则：`{PROVIDER}_API_KEY`（大写），例如：

| 提供商 | 环境变量 |
|--------|----------|
| 智谱 GLM | `GLM_API_KEY` |
| DeepSeek | `DEEPSEEK_API_KEY` |
| OpenAI | `OPENAI_API_KEY` |
| Ollama | `OLLAMA_API_KEY` |

Windows 持久化设置（PowerShell，重启后仍生效）：

```powershell
[Environment]::SetEnvironmentVariable("GLM_API_KEY", "你的真实密钥", "User")
```

也可在「设置」页 GUI 表单中填写后保存（写入 `config.yaml`，重启生效）。`config/config.yaml` 中的 `api_key` 字段默认为占位符 `"your-api-key-here"`，未配置环境变量且未在 GUI 填写时 AI 报告功能不可用。

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Alt+P | 暂停/恢复采集 |
| Ctrl+Alt+R | 生成今日报告 |
| Ctrl+Alt+N | 隐私模式 (30分钟) |
| Ctrl+Alt+I | 速记：唤起主窗口并聚焦速记输入框（v5.4） |
| Ctrl+K | 全局搜索命令面板（跨报告 / 待办 / 速记 / 输入记录） |

> v5.4 起，Web GUI 模式下这四个 `Ctrl+Alt+*` 快捷键同样可用（此前仅托盘/GUI 模式注册）。

## 数据存储

- 数据库: `data/blackbox.db`（sessions / window_events / text_segments / clipboard_records / daily_reports / period_reports / todos / todo_advices / todo_notify_log / notes / projects 等表）
- 日志导出: `data/logs/YYYY-MM-DD.md`
- AI 日报: `data/logs/YYYY-MM-DD_HHMMSS_report.md`
- AI 周报: `data/logs/YYYY-MM-DD_weekly.md`（周一日期）
- AI 月报: `data/logs/YYYY-MM_monthly.md`
- 导出文件: `data/exports/`（报告 HTML、待办 CSV 等导出产物）
- 待办删除归档: `data/exports/todo_archive_YYYY-MM.md` + `todo_archive.jsonl`（append-only，恢复/彻底删除不回改）
- 洞察收件箱: 由 `insight.inbox_dir` 指定（默认空 = 不落盘）；速记保存时同步写 `YYYY-MM-DD_HHMM.md`

## 配置文件

编辑 `config/config.yaml` 可修改：

- **活动记录开关**: `collection.keyboard_enabled`
- **剪贴板监控**: `collection.clipboard_enabled`
- **空闲阈值**: `collection.idle_threshold`（默认 300 秒）
- **AI 模型**: `ai.glm.model`（glm-4-flash / glm-4.5-flash / glm-4.7）
- **应用黑名单**: `privacy.app_blacklist`
- **采集准确性**: `collection.accurate_mode`（默认 true；false = 回退纯键盘 + 拼音链路）
- **洞察收件箱**: `insight.inbox_dir`（速记双写落盘目录，留空 = 仅入库；也可在速记页面板配置，保存后热生效）

## 隐私说明

- 所有数据 100% 本地存储，不上传任何服务器
- 密码管理器等黑名单应用自动跳过（前台时不记录）
- 身份证 / 银行卡 / 手机号 / 邮箱 / 密码上下文 / JWT Token / API Key (sk-xxx) / IPv4 地址 / PEM 私钥等自动脱敏
- 随时可点击「隐私模式」暂停记录
- 数据可随时删除（删除 data 目录即可）
